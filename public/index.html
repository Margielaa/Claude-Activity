How it's measured

Exact: every total, the split by token type, by model, project, session and time. They come straight from the usage Anthropic records for each model turn in Claude Code's transcripts, counted once per turn (a turn is spread over several transcript lines that repeat its usage). AI code reviews and fixes keep no transcript, so their recorded usage is added separately.

Estimated, but always adding up to the exact totals: which action used the tokens. A turn's output is split across its reply text and each tool call's input by size; what the visible text doesn't account for is thinking. A turn's new context is split across what was added since the previous turn: each tool's results, your messages, system reminders and Claude's previous reply being sent back. On a session's first turn the rest is setup (system prompt, tools, memory); after a pause of more than 5 minutes the prompt cache has expired and the whole conversation is re-sent ("Re-caching after a pause"). Cache reads are the conversation history re-read on every turn.

Est. cost weights tokens the way plan limits do, using API price ratios: input 1, cache write 1.25, cache read 0.1, output 5, times 5 for Opus or Fable, 3 for Sonnet and 1 for Haiku. It shows shares, not dollars.
